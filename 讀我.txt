施工照片下載工具
================

【第一次使用】

  雙擊  安裝.bat

  它會自動：
    1. 檢查／安裝 Python
    2. 安裝需要的套件
    3. 帶你一頁一頁申請 Google API 金鑰，申請完貼上就自動存好
    4. 在桌面放一個「施工照片下載」捷徑

  安裝過程請保持網路暢通。全部大約 5 分鐘。


【以後每次使用】

  雙擊桌面的「施工照片下載」

    → 按「讀取日期」
    → 勾選要下載的日期（可複選）
    → 按「開始下載」

  照片會存成：
    你選的資料夾\20260830\ ...照片...
    你選的資料夾\20260830.zip   （同一天打包好的）


【出問題】

  · 雙擊沒反應       → 看資料夾裡有沒有 error.log
  · 套件安裝失敗     → 檢查網路／Proxy，再重跑一次 安裝.bat
  · 想換 API 金鑰    → 再雙擊一次 安裝.bat

  更詳細的說明在 README.md
