資料夾檔案下載工具
==================

【第一次使用】

  雙擊  安裝.bat

  它會自動：
    1. 檢查／安裝 Python
    2. 安裝需要的套件
    3. 請你貼上要下載的雲端硬碟資料夾連結
    4. 帶你一頁一頁申請 Google API 金鑰，申請完貼上就自動存好
    5. 在桌面放一個「資料夾檔案下載」捷徑

  安裝過程請保持網路暢通。全部大約 5 分鐘。


【以後每次使用】

  雙擊桌面的「資料夾檔案下載」

    → 按「讀取清單」
    → 勾選要下載的資料夾或檔案（可複選；上方「排序」可切換名稱升冪／降冪）
    → 按「開始下載」

  檔案會存成：
    你選的資料夾\子資料夾A\ ...（保留原本的子資料夾）
    你選的資料夾\子資料夾A.zip  （有勾「打包成 zip」時）
    你選的資料夾\單獨勾選的檔案

  Google 文件、試算表這類線上格式不會下載。


【出問題】

  · 雙擊沒反應       → 看資料夾裡有沒有 error.log
  · 套件安裝失敗     → 檢查網路／Proxy，再重跑一次 安裝.bat
  · 想換 API 金鑰    → 再雙擊一次 安裝.bat
  · 想換資料夾       → 直接在程式視窗的「資料夾」欄位貼新的連結

  更詳細的說明在 README.md
