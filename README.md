# 施工照片下載工具

從雲端硬碟「施工中照片上傳 (File responses)」勾選日期，把該日照片下載回本機，每個日期另外打包一個 zip。
只認 `YYYYMMDD` 命名的日期子資料夾（`20260830`），根目錄那些散檔不處理。

## 安裝與使用

第一次雙擊 **`安裝.bat`**（裝 Python／套件 → 帶你申請 API 金鑰並自動存好 → 建桌面捷徑）。
之後雙擊桌面「施工照片下載」→ 讀取日期 → 勾選 → 開始下載。

輸出：

```
你選的資料夾\20260830\  照片
你選的資料夾\20260830.zip
```

- 「跳過已下載」預設開啟：檔名與大小相同就不重抓
- 下載中可取消；未完成的檔案以 `.part` 暫存，不會留半個檔
- 要換金鑰：再跑一次 `安裝.bat`

## 發給同事

把整個資料夾壓縮發出去即可。若要讓同事免申請金鑰，在資料夾內放
**`預設金鑰.txt`**（只寫金鑰那一串），安裝精靈會直接採用並當場驗證。

> 共用前先把該金鑰設定成「API 限制 → 只勾 Google Drive API」。

## 檔案分工

| 檔案 | 負責 |
|---|---|
| `安裝.bat` / `執行.bat` | 安裝與日常啟動；金鑰是空的會自動轉去安裝 |
| `setup_wizard.py` | 設定精靈：引導申請金鑰、驗證、寫入 `settings.json` |
| `main.py` | 進入點；無主控台時以對話框報錯並寫 `error.log` |
| `config.py` | `settings.json` 讀寫與預設值 |
| `drive_client.py` | Drive API：列日期資料夾、列照片、下載單檔、錯誤翻譯。不碰畫面 |
| `downloader.py` | 背景執行緒：下載流程、跳過規則、打包 zip、進度回報 |
| `ui_main.py` | PyQt5 畫面 |
| `smoke_test.py` | 離線自我測試（12 項），**改完程式先跑這個** |
| `診斷.bat` / `診斷.py` | 下載失敗時跑這支，印出 Google 實際回了什麼 |

```
python drive_client.py 你的金鑰    # 單獨驗 Drive 連線
python 診斷.py                     # 下載被擋時，比對四種端點／UA 組合
python smoke_test.py               # 離線測試（12 項）
```

## 疑難排解

| 狀況 | 處理 |
|---|---|
| `API 金鑰無效` | 金鑰沒複製完整 |
| `還沒啟用 Google Drive API` | 到 Cloud 主控台啟用，等 1~2 分鐘 |
| `金鑰被限制條件擋下來了` | 金鑰的「應用程式限制」要設成**無** |
| `找不到這個資料夾` | 資料夾 ID 錯，或共用權限被改成非公開 |
| 讀到 0 個日期資料夾 | 底下沒有 `YYYYMMDD` 命名的子資料夾 |
| 雙擊沒反應 | 看資料夾裡的 `error.log` |
| `Google 回了一頁網頁而不是資料` | 防濫用限流。程式會自動重試並改走備用端點；若整批停下，等 10~30 分鐘再抓，或跑 `診斷.bat` 看細節 |
| 套件安裝失敗 | 檢查網路／Proxy，重跑 `安裝.bat` |

雲端資料夾共用權限為「知道連結的任何人 — 檢視者」，即本工具所需的最小權限。
