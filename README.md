# 資料夾檔案下載工具

從「知道連結的任何人都能檢視」的 Google 雲端硬碟資料夾，勾選要的子資料夾或檔案，下載回本機。
勾選的資料夾會連同所有子資料夾一起下載並保留原本的結構，也可以另外打包成 zip。

## 安裝與使用

第一次雙擊 **`安裝.bat`**（裝 Python／套件 → 貼上要下載的資料夾連結 → 帶你申請 API 金鑰並自動存好 → 建桌面捷徑）。
之後雙擊桌面「資料夾檔案下載」→ 讀取清單 → 勾選 → 開始下載。

清單列的是資料夾最上層的項目（資料夾在前、檔案在後），可用清單上方的「排序」切換名稱升冪／降冪，
切換時已勾選的項目會保留，選擇會記在 `settings.json`。輸出：

```
你選的資料夾\子資料夾A\…        勾選的資料夾（含所有子資料夾）
你選的資料夾\子資料夾A.zip      勾「打包成 zip」時，每個資料夾一個
你選的資料夾\報告.pdf           單獨勾選的檔案
```

- 「跳過已下載」預設開啟：檔名與大小相同就不重抓
- 下載中可取消；未完成的檔案以 `.part` 暫存，不會留半個檔
- Google 文件、試算表、簡報這類線上格式沒有實體檔案，**不會列出也不會下載**
- 要換金鑰：再跑一次 `安裝.bat`；要換資料夾：直接在程式視窗改

## 發給同事

把整個資料夾壓縮發出去即可。若要讓同事免申請金鑰，在資料夾內放
**`預設金鑰.txt`**（只寫金鑰那一串），安裝精靈會直接採用並當場驗證。

> 共用前先把該金鑰設定成「API 限制 → 只勾 Google Drive API」。
> `settings.json`（含金鑰）與 `預設金鑰.txt` 已列在 `.gitignore`，不會被推上 GitHub。

## 檔案分工

| 檔案 | 負責 |
|---|---|
| `安裝.bat` / `執行.bat` | 安裝與日常啟動；金鑰是空的會自動轉去安裝 |
| `setup_wizard.py` | 設定精靈：問資料夾連結、引導申請金鑰、驗證、寫入 `settings.json` |
| `main.py` | 進入點；無主控台時以對話框報錯並寫 `error.log` |
| `config.py` | `settings.json` 讀寫與預設值 |
| `drive_client.py` | Drive API：列項目、遞迴走訪子資料夾、下載單檔、錯誤翻譯。不碰畫面 |
| `downloader.py` | 背景執行緒：下載流程、跳過規則、打包 zip、進度回報 |
| `ui_main.py` | PyQt5 畫面 |
| `smoke_test.py` | 離線自我測試（12 項），**改完程式先跑這個** |
| `診斷.bat` / `診斷.py` | 下載失敗時跑這支，印出 Google 實際回了什麼 |

```
python drive_client.py 你的金鑰 資料夾連結   # 單獨驗 Drive 連線
python 診斷.py                              # 下載被擋時，比對四種端點／UA 組合
python smoke_test.py                        # 離線測試（12 項）
```

## 疑難排解

| 狀況 | 處理 |
|---|---|
| `API 金鑰無效` | 金鑰沒複製完整 |
| `還沒啟用 Google Drive API` | 到 Cloud 主控台啟用，等 1~2 分鐘 |
| `金鑰被限制條件擋下來了` | 金鑰的「應用程式限制」要設成**無** |
| `找不到這個資料夾` | 資料夾 ID 錯，或共用權限不是「知道連結的任何人」 |
| 清單是空的 | 資料夾裡只有 Google 文件類的線上格式，或真的是空的 |
| 雙擊沒反應 | 看資料夾裡的 `error.log` |
| `Google 回了一頁網頁而不是資料` | 防濫用限流。程式會自動重試並改走備用端點；若整批停下，等 10~30 分鐘再抓，或跑 `診斷.bat` 看細節 |
| 套件安裝失敗 | 檢查網路／Proxy，重跑 `安裝.bat` |

雲端資料夾共用權限需為「知道連結的任何人 — 檢視者」，即本工具所需的最小權限。
